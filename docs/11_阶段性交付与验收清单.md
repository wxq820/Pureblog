# 11 阶段性交付与验收清单

## 1. 阶段一：模块化单体闭环（当前已交付）

### 交付物
- [x] 后端 Spring Boot 3 多模块工程（11 个模块，含 pureblog-tree）
- [x] 前端门户（Vue 3 + TS + Pinia + Vue Router）
- [x] 管理后台接口（`pureblog-admin` 模块 + 可选的 `pureblog-admin-web` 前端）
- [x] 统一响应 / 异常 / 日志
- [x] 配置文件（application.yml + application-dev.yml）
- [x] Docker Compose（MySQL + Redis）
- [x] 数据库脚本（scripts/schema*.sql + scripts/seed_*.sql）
- [x] 目录树初始化脚本（backend/sql/init_tree.sql）

### 验收点
- 后端能启动：`mvn -pl pureblog-app -am spring-boot:run`
- 前端能启动：`pnpm dev` 或 `npm run dev`
- 健康检查可访问：`GET /actuator/health` 返回 200 + `status: UP`
- 登录接口可访问：`POST /api/auth/login {username:"admin",password:"123456"}`
- 目录树接口：`GET /api/tree/public/list` 返回非空
- 树节点过滤：`GET /api/article/list?treeNodeId=4` 只返回挂在该节点下的文章
- 排序：`GET /api/article/list?sortBy=likeCount&sortOrder=desc` 按点赞数降序（置顶优先）
- 图片上传：`POST /api/upload/image` 返回 `{url, name, size}`，详情页可访问 `/static/uploads/...`
- 前后端联调通：门户登录 → 编辑器上传图 → 发布 → 详情图能渲染 → 首页点树节点 → 右侧列表只剩该节点下的文章

## 4. 面试展示顺序建议

1. 项目定位（个人博客为主、代码能力完整）
2. 架构图（单仓多模块 + 进程内事件）
3. 数据模型（关键表 + 关系，含 `pb_tree` / `pb_tree_node`）
4. 发布链路（写完事务 → 失效缓存 → 计数更新）
5. 搜索链路（MySQL 多表 JOIN + LIKE + 服务端转义高亮）
6. 热点链路（缓存 + 热度 ZSet + 定时兜底）
7. 目录树导航链路（叶子校验 + 物化路径 + 计数一致性）
8. 一致性策略（Cache Aside + 事件驱动）
9. 鉴权设计（JWT + 双 Token + 黑名单 + ThreadLocal）
10. 后续演进（OSS / Kafka / 服务化）的取舍逻辑

## 5. 验收脚本参考

```bash
# 1. 启动基础设施 (项目根目录, 唯一 compose 入口)
docker compose up -d

# 2. 初始化数据库 (31 张表全量建库)
docker exec -i pureblog-mysql mysql -uroot -p123456 pureblog < scripts/schema.sql

# 3. 初始化目录树 / 小工具 / 财务模块
docker exec -i pureblog-mysql mysql -uroot -p123456 pureblog < backend/sql/init_tree.sql
docker exec -i pureblog-mysql mysql -uroot -p123456 pureblog < backend/sql/init_widget.sql
docker exec -i pureblog-mysql mysql -uroot -p123456 pureblog < backend/sql/init_finance.sql

# 4. 启动后端
cd backend
mvn -pl pureblog-app -am spring-boot:run

# 6. 验证
curl http://localhost:8080/actuator/health
curl -X POST http://localhost:8080/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"123456"}'

curl http://localhost:8080/api/tree/public/list
curl 'http://localhost:8080/api/article/list?treeNodeId=4'
curl -F "file=@./test.png" \
  -H "Authorization: Bearer <token>" \
  http://localhost:8080/api/upload/image

# 7. 启动前端
cd ../frontend/pureblog-portal
npm install && npm run dev
```
