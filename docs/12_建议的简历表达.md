# 12 建议的简历表达

## 1. 项目一句话描述

基于 Spring Boot、Redis、Kafka、Elasticsearch 构建的高性能博客平台，围绕文章发布链路、全文搜索链路和热点读取链路，展示缓存优化、异步事件驱动、最终一致性和 JVM 性能治理能力。

## 2. 可写进简历的要点

- 设计并实现文章发布、评论审核、站内通知、热榜统计等核心业务闭环
- 基于 Redis 实现热点文章缓存、阅读量计数与限流能力，优化高频读场景性能
- 基于 Kafka 解耦文章发布后的搜索索引同步、通知发送和统计刷新，降低主链路耗时
- 基于 Elasticsearch 实现标题/摘要/正文/标签的全文检索、高亮与过滤能力
- 设计 MySQL + Redis + Elasticsearch 的一致性处理方案，并支持索引重建与补偿
- 通过 JFR、GC 日志、线程池指标等手段完成接口耗时和 JVM 运行状态观测

## 3. 面试不要这么说
- “为了秀技术我就全上了”
- “博客项目所以必须用微服务和 Dubbo”
- “评论怕压力太大所以先存内存队列再落库”

## 4. 面试更推荐这么说
- “我先用模块化单体保证业务闭环，再用 Kafka 承担异步副作用链路，后续预留服务化演进能力”
- “Redis 和 ES 都是围绕真实业务问题引入的：前者解决热点读取，后者解决全文检索”
- “项目重点不是组件数量，而是链路完整性与一致性治理”
