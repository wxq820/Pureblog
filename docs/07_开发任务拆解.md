## 2. 后续可扩展任务

### 2.1 文件上传
- 接入 MinIO（`pb_file` 表已建）
- 文件上传接口 / URL 回显
- 封面图与正文图片上传

### 2.2 限流与防刷
- 登录限流（按 IP）
- 评论限流（按用户）
- 通用 Redis 限流（注解 + Lua）

### 2.3 可观测
- 接入 Micrometer
- 暴露 `/actuator/metrics`、`/actuator/prometheus`
- 关键接口埋点
- 线程池指标、Redis 命中率、ES 搜索耗时

### 2.4 跨进程消息
- 引入 Redis Stream（替换 `ApplicationEventPublisher`）
- 或引入 Kafka（`pb_kafka_outbox` 表已建）
- 消费幂等表

### 2.5 服务化
- 拆 `pureblog-search` 为独立服务
- 拆 `pureblog-notification` 为独立服务
- 引入 Spring Cloud OpenFeign / Dubbo

### 2.6 安全与合规
- 真实图形验证码（当前是随机 4 位数）
- 密码强度校验
- 上传文件类型白名单
- IP 黑名单

### 2.7 数据治理
- 文章日统计定时落库（`pb_article_stats` 表已建）
- Outbox 模式
- 慢 SQL 监控

### 2.8 性能与体验
- 多级缓存（Caffeine + Redis）
- 索引预热
- 文章封面自动压缩
- 静态资源 CDN

### 2.9 压测与调优
- JMeter / k6 脚本
- JVM 调优
- GC 日志分析
- 热点文章写入合并

1. 改动文件清单
2. 接口与表结构是否有变更
3. 如何本地验证
4. 下一步建议

如果要新增模块，遵循 `docs/03_项目目录建议.md` 中的命名规范。
