# 07 开发任务拆解

## 1. 开发策略

不要让 Cursor 一次性生成整个系统。正确做法是：

- 按模块拆
- 按层拆
- 按阶段拆
- 每次只让 Cursor 完成一个“可验证的小闭环”

---

## 5. 任务分配建议（给 Cursor 的方式）

### 方式一：模块级
一次只让 Cursor 做一个模块：
- “先实现 article 模块后端”
- “再实现 comment 模块前端”

### 方式二：层级级
一次只做某一层：
- 先生成 entity + mapper
- 再生成 service
- 再生成 controller
- 最后生成前端页面

### 方式三：闭环级
优先做一条最短闭环：
- 注册登录闭环
- 文章发布闭环
- 搜索闭环
- 评论审核闭环

## 7. 给 Cursor 的任务要求

每个任务都必须输出：

1. 修改了哪些文件
2. 为什么这样实现
3. 是否涉及数据库变更
4. 如何本地验证
5. 下一步建议做什么

这样你审阅时最省事。
